# Built-in kernel types

This directory holds the kernel type implementations that ship with jupyter.nix
(`ipykernel`, `ihaskell`, `ijulia`, …). They are registered in
[`../kernel-types.nix`](../kernel-types.nix).

For a guide on how kernel types work and how to write your own, see
[`doc/kernel-authoring.md`](../../doc/kernel-authoring.md).
